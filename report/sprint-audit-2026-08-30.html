重要な発見事項

P1 / 統合・リリース阻害

上流と乖離した未コミット差分を出荷できない

ローカル main は origin/main より 20 コミット遅れています。未コミットの履歴パス削除とログ変更は、上流にも同目的の変更があり、取り込み時に重複・競合・片方の安全対策の消失を起こし得ます。

証跡: HEAD c79d31d、origin/main 45f7264。上流には ca42265 fix: stop persisting imported audio paths と 2c4320d fix: redact sensitive runtime logs が存在。

対応: clean worktree で origin/main を基準に差分を三者比較し、重複を捨てずに意図単位で統合、再テストしてから PR 化する。

P1 / 同時実行

プロセス開始はまだ原子的ではない

startPython は状態ロックを解除してから Process.run() を呼びます。その間に第二の開始要求が来ると、まだ isRunning == false の一つ目を「未起動」と誤認して管理対象を上書きし、最初の子プロセスを追跡不能にできます。

該当: KotoType/Sources/KotoType/Transcription/PythonProcessManager.swift 95–143 行。追加テストは 24 並行送信と世代比較であり、開始↔開始・開始↔停止の競合を再現していない。

対応: stopped / starting / running / stopping の状態遷移を一つの排他境界にし、開始中は再要求を拒否または合流させる。並行 start/stop で孤立 PID が残らない回帰テストを追加する。

P2 / プライバシー

このローカル状態の診断出力は絶対パスを露出する

Logger はメッセージをそのままファイル・標準出力へ出し、プロセス管理は音声パス、Python stderr は内容全体を渡します。実行した Swift テストでも Application Support と一時音声ファイルの絶対パスが端末に出ました。ファイルの owner-only 権限は共有された stdout/stderr を保護しません。

該当: Logger.swift 54–67 行、MultiProcessManager.swift 131・228 行、PythonProcessManager.swift 168–177 行、python/whisper_server.py の traceback 記録。上流にはパスを <path> へ置換する未取り込み修正とテストがある。

対応: 上流の Swift/Python 両方のサニタイズを統合し、stderr は内容でなく型・長さを記録する。既存ログの扱いは保存期間ポリシーを決めてから別途実施する。

P3 / 残置コード

テスト専用の本番 API が残っている

shouldHandleProcessEvent(generation:currentGeneration:) は production code から一度も呼ばれず、テストだけが参照しています。実際の判定は private な isCurrentGeneration です。

該当: PythonProcessManager.swift 216–218 行。参照は PythonProcessManagerTests.swift のみ。

対応: 削除し、世代をまたぐ実プロセス/pipe コールバックの統合テストへ置換する。
